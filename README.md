\# Cognifyz Data Analysis Internship



\## Project Overview



This repository contains the tasks completed as part of the Cognifyz Data Analysis Internship. The projects focus on exploring restaurant data, identifying patterns, performing statistical analysis, and presenting findings through visualizations.



\## Technologies Used



\* Python

\* Pandas

\* NumPy

\* Matplotlib

\* Seaborn

\* CSV datasets



\## Project Structure



\* \*\*Level 1:\*\* Four data analysis tasks.

\* \*\*Level 2:\*\* Four advanced data analysis tasks.



Each task folder contains the relevant Python source code and generated results.



\## Level 1 Tasks



1\. Top Cuisines Analysis

2\. City Analysis

3\. Price Range Analysis

4\. Online Delivery Analysis



\## Level 2 Tasks



1\. Restaurant Ratings Analysis

2\. Cuisine Combination Analysis

3\. Geographic Analysis

4\. Restaurant Chain Analysis



\## Outputs



The projects generate CSV files containing analysis results and PNG charts to visualize important findings.



\## How to Run



1\. Install Python.

2\. Install the required libraries:

&#x20;  `pip install pandas numpy matplotlib seaborn`

3\. Open the desired task folder.

4\. Run its Python script using:

&#x20;  `python filename.py`



Replace `filename.py` with the actual Python script name. Additional libraries may be needed depending on the task.



\## Submission



This folder contains the completed Level 1 and Level 2 tasks, their source code, datasets, and generated outputs.
